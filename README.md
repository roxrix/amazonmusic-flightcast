# Amazon Music × Flightcast — creator one-pager

The document we send to creators about the four Amazon Music marketing
programmes: the Times Square billboard, being featured in the app, ads on social
paid for by Amazon, and the audio ad swap.

- **`index.html`** — the document. One self-contained file: images and fonts are
  inside it, so it opens the same on any machine, online or off.
- **`onepager.pdf`** — the same thing as an 8-page A4 PDF, for emailing.

Nothing is built here. These two files are the finished document.

## Keep this repository private

The document contains material that is not ours to publish:

- Screenshots from Amazon's paid media deck, which is marked CONFIDENTIAL on
  every slide.
- Photographs of other people's shows: Hoda Kotb, Jon Stewart, Dax Shepard,
  Keke Palmer, Zach Sang, Malcolm Gladwell, Oprah Winfrey, Chrissy Teigen, and
  the hosts of Chicks in the Office and Watch What Crappens.
- The Amazon Music wordmark, used under our partnership rather than a public
  licence.

Clear the deck screenshots with Amazon before this goes to creators, and do not
switch on GitHub Pages or any public hosting for it.

## Changing the copy

`index.html` is too large for GitHub's in-browser editor, so edits happen
outside the repo: change the file locally, then upload it here again with
**Add file → Upload files**, which replaces it.

Two rules worth keeping:

- Every number in the document is sourced from Amazon's own text or from Rox's
  confirmation on how video reaches Amazon Music. Do not round or estimate.
- No em dashes, per house style.

After any change, check the last bullet of the longest list is still there:
"A tagline, 40 characters or less", at the foot of the billboard page. It is the
first thing to disappear if a page overflows.
